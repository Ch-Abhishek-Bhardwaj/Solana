PDA => program derived address

Typical account

 private key + public key = account address

PDA

no private key -> only public key

How is it created ?
Created deterministically using 
-program ID
other predefined inputs <- seeds & bump

Why is it useful?
- no private key needed
  less key management
  no one can sign -> only program that owns it can modify.
- can be regenerated by anyone
- can be used to store data
- can be used to store tokens

Ceate a hashmap like data structure
   
deterministic address


Example:
A program to lock user sol for 1 year
 PDA = account where sol is locked

Abhi ---->Lock program ------> PDA( Abhi's lock Account -lock expiry)
     (1 sol )         (1 sol )


program Id                          Seed                                bump
Lock program                       user public key
                                   user Specific random number          255




what is a bump in PDA?
Bump is a number (0  ~ 255)
    to ensure that the pDA address is not a point on th ED25519 curve

    
PDA is derived from
- program ID
- seeds
- bump
